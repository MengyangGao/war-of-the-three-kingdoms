# 三分天下 · 风云牌局

原创视觉、纯前端、离线可玩的三国题材策略卡牌游戏。

## 开始游戏

直接打开根目录的 `index.html`。这是一个约 1.78 MiB 的完整独立文件，已经内嵌全部逻辑、样式、程序化音效、24 张开放许可历史画像和逐项许可账本。

无需安装、无需服务器、无需联网，也可以直接部署到 GitHub Pages。对局会在安全的回合边界自动保存；刷新或关闭页面后可选择“继续上次牌局”。

> 本项目不隶属于或代表任何商业桌游、电子游戏及其权利人；不使用第三方游戏的标志、界面截图、卡面或音频。

- 94/94 规则、架构、事件、检查点、时间线与平衡断言通过。

## 十项本质性优化

1. **逐人数身份平衡矩阵（已完成）**：分别约束 3–8 人胜率、P95 回合和异常，而不是只看 8 人总结果。
2. **可恢复执行状态（已完成）**：完整保存牌面、RNG、玩家、日志和下一行动者，只从安全边界恢复。
3. **结构化事件模型（已完成）**：事件拥有 ID、类型、回合、阶段、行为者、目标与领域字段。
4. **UI 按职责拆分（已完成）**：渲染、通用交互、提示、视觉、活动和弹窗分离。
5. **统一可取消时间线（已完成）**：动画、节奏与输入延时可单项、分组或全局取消。
6. **隐藏身份信念模型**：AI 不再直接读取他人真实身份，只依据公开行为维护独立概率。
7. **AI 决策解释与难度档**：输出候选评分、关键理由和风险；难度改变搜索深度而非规则。
8. **完整行动重放**：记录规范化决策，支持导出、导入、逐事件回放和精确复现错误。
9. **单文件冷启动预算**：画像按本局角色惰性解码，约束可交互时间、内存和 DOM 峰值。
10. **数据驱动规则与属性测试**：统一卡牌/技能契约，并在每个结算边界随机验证牌唯一性和动作合法性。
