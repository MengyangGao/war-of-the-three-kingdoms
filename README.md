# 三分天下 · 风云牌局

原创视觉、纯前端、离线可玩的三国题材策略卡牌游戏。

## 开始游戏

直接打开根目录的 `index.html`。该文件约 1.76 MiB，已经内嵌：

- 全部游戏逻辑、界面样式和程序化音效
- 24 张经过许可审计的历史人物画像
- 完整的图片来源与许可账本

不需要安装依赖、启动服务器或下载其他资源，也可以直接部署到 GitHub Pages。

> 本项目不隶属于或代表任何商业桌游、电子游戏及其权利人；不使用第三方游戏的标志、界面截图、卡面或音频。

## 进一步全面审计：十项高价值改进

以下不是泛泛的“重构建议”，而是按当前代码路径、规模和实测结果得到的下一阶段优先事项。

1. **将互动记录升级为结构化事件。** 当前角色最近事件通过中文战报中的角色名识别参与者，改文案可能破坏关联。应由引擎直接产生 `{actorId, targetIds, action, cardId, skillId, amount}`，UI 只负责本地化展示。

2. **拆分 UI 巨型模块。** 构建前的 `70-ui.js` 已达到 1322 行，同时负责渲染、弹窗、HumanAgent、战报和输入映射。应拆成 Renderer、Dialogs、InteractionController、ActivityView，并通过只读视图模型通信。

3. **把卡牌效果改成数据驱动注册表。** `30-cardeffects.js` 约 915 行，合法性判断和结算容易跨函数漂移。每张牌应拥有统一的 `canUse / legalTargets / resolve / aiValue` 契约，并以共享校验器服务人类与 AI。

4. **把引擎流程拆成可序列化状态机。** `40-engine.js` 约 1001 行，大量流程依赖异步函数调用栈。显式的 phase/action/effect 状态机能支持暂停、恢复、调试和确定性重放，也能降低异步中途状态难以保存的问题。

5. **实现存档和可重放对局。** 当前只有随机种子，没有持久化行动日志。保存 seed、版本号和规范化决策序列后，可以中途续局、分享精彩对局，并把线上 bug 还原成固定回归用例。

6. **系统性校准身份 AI。** 最近 500 局压力结果为主忠方 177、反贼 315、内奸 8，内奸胜率约 1.6%，明显缺乏竞争力。应建立按人数、身份、武将的胜率矩阵，并优化内奸的局势控制、救主阈值和残局决策。

7. **统一可取消的动画调度器。** 当前动画存在较多独立 `setTimeout`，速度切换只影响后续时长，重开或关闭弹窗时也难以集中取消。应使用单一时间线、取消令牌和逻辑时间倍率，使暂停、跳过动画和重开安全一致。

8. **增加“卡牌特定作用范围”预览。** 当前距离标签展示普通攻击范围，但顺手牵羊、借刀杀人、全体锦囊等采用不同目标规则。选中卡牌后应在每个角色上直接显示“合法 / 距离不足 / 技能免疫 / 已有同名延时牌”等具体原因。

9. **补齐完整无障碍交互。** 已有键盘焦点和 ARIA，但弹窗尚需焦点锁定、关闭后焦点归还、事件播报节流，以及移动端替代 hover/title 的详情入口。这会同时改善键盘、读屏和触屏体验。

10. **建立源码分支到发行文件的 CI。** 当前仓库刻意只保留发行版，直接编辑 1.76 MiB 的生成 HTML 不可维护。建议保留 `source` 分支或独立源码仓库，由 GitHub Actions 执行规则测试、500 局抽样、资产许可检查、浏览器冒烟测试，再自动生成并发布根目录 `index.html`。
