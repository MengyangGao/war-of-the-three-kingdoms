# 风云弈策 · 汉末牌局

一款纯前端、离线可玩的汉末题材隐藏阵营策略卡牌游戏。支持 3–8 人牌局，其余角色由电脑控制。

![开局大厅](docs/lobby.jpg)

![牌桌界面](docs/game.jpg)

## 游戏特点

- 四种隐藏身份，各有不同的胜利目标
- 27 名可选武将，每名武将拥有独立技能
- 位置、座次、距离和可攻击目标直接显示在牌桌上
- 结构化事件提示会说明谁对谁使用了卡牌或技能
- 每名角色保留最近五次互动，方便追踪局势
- 慢速、标准、快速和极速四档对局速度
- 支持暂停推进、跳过演出、自动存档和继续游戏
- 支持挑战码复现同一开局，也可导出个人存档码
- 兼容桌面与移动浏览器，支持键盘操作和减少动态效果

## 开始游戏

1. 下载 [`index.html`](index.html)。
2. 使用 Chrome、Edge、Firefox 或 Safari 打开。
3. 选择 3–8 人牌局和自己的武将。
4. 点击“开始牌局”。

游戏无需安装、构建或联网。分享给其他人时，只需发送 `index.html`；全部规则、界面、图片、音效和许可信息都已经包含在文件中。

如果希望通过网址分享，也可以把仓库发布到 GitHub Pages：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/ (root)` 目录并保存。

## 基本操作

在自己的出牌阶段：

1. 点击带有“可用”标记的手牌或技能。
2. 按提示选择目标；绿色标记表示当前合法目标。
3. 检查行动者、卡牌、目标和效果预览。
4. 点击确认执行；没有其他行动时点击“结束出牌”。

牌桌中央会显示座次、距离、攻击范围、当前行动者和最近关键事件。点击角色、距离标记或事件条，可以查看更完整的解释。

顶部工具栏可以调整对局速度、暂停推进、打开玩法引导、查看图鉴、修改显示设置或查阅完整战报。手牌也可使用数字键快速选择。

## 身份目标

| 身份 | 胜利目标 |
| --- | --- |
| 盟主 | 击败所有逐鹿者和独行客 |
| 护军 | 保护盟主并击败其敌人 |
| 逐鹿者 | 击败盟主 |
| 独行客 | 成为最后存活的角色 |

盟主身份始终公开，其他角色的身份需要结合公开行动和事件逐步判断。你的身份目标与当前公开进度会持续显示在个人区域。

## 存档与分享

- **自动存档**：游戏会在安全的行动边界保存，重新打开后可继续。
- **个人存档码**：用于跨设备迁移未完成的牌局，其中包含隐藏身份、手牌和牌序，请勿公开分享。
- **挑战码**：用于复现相同人数、座次、身份、武将和牌序，适合邀请别人挑战同一开局。

浏览器的本地数据只保存在当前设备。清除浏览器数据前，建议先导出个人存档码。
