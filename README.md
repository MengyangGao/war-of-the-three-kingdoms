# 三分天下 · 风云牌局

原创视觉、纯前端、离线可玩的三国题材策略卡牌游戏。

## 开始游戏

直接打开根目录的 `index.html`。它是一个完整独立文件，已经内嵌全部规则、界面、程序化音效、24 张开放许可历史画像和逐项许可账本。

无需安装、无需服务器、无需联网；也可以直接部署到 GitHub Pages。牌局会在安全的回合边界自动保存，刷新或关闭后可以继续。

> 本项目不隶属于或代表任何商业桌游、电子游戏及其权利人；不使用第三方游戏的标志、界面截图、卡面或音频。

## 本轮交互改进

- 选牌后直接说明每名角色为何可选或不可选，例如“距离 2 ＞ 范围 1”“没有可获得的牌”或“受武将技能保护”。
- 操作区持续显示“选牌—选目标—确认”三步状态，并列出已经选择的牌、费用和目标。
- 续局卡片显示人数、武将、回合和保存时间；删除需要二次确认，损坏存档会给出页面内提示。
- 手机端不再隐藏战况条和玩家最近互动；390×844 下仍可同时看到指令、确认按钮和横向手牌。
- 顶栏速度可随时切换；动画进行中可以立即“跳过当前演出”，不会改变规则结果。
- 每名角色保留最近五条互动，使用 `→` / `←` 区分谁发起、谁承受。
- 弹窗支持焦点圈定、Escape 关闭和焦点返回；技能、装备、判定牌与武将入口均可用键盘操作。

## 验证结果

- 98/98 规则、架构、事件、检查点、时间线、目标解释与平衡断言通过。
- 60 局整局模拟通过：0 异常、0 牌问题、0 事件问题、0 未结束。
- 3–8 人各 200 局固定种子平衡矩阵通过。
- 桌面 5 人局真实点击验证：选牌、合法/非法目标原因、选择摘要、确认和取消。
- 390×844 手机视口真实续局验证：战况、互动、三步指令、按钮和手牌均可操作。
- 演出跳过、续局元数据、弹窗焦点返回和独立单文件冷启动均通过真实浏览器验证。
- 浏览器控制台 0 error / 0 warning；单文件外部资源自检通过。

仓库内 Python Playwright 套件因当前 Python 环境未安装 `playwright` 而未单独执行；同一轮已通过内置真实浏览器覆盖关键桌面、手机和单文件路径。

## 下一阶段十项实质方向

1. **战报事件检查器**：展开结构化来源、目标、牌/技能、结果和关联事件。
2. **渐进式新手引导**：只在首次遇到身份、距离、响应等概念时提示，可跳过、可重置。
3. **可量化可用性回归**：本地记录首次合法出牌时间、无效点击、取消率和响应超时。
4. **隐藏身份信念模型**：AI 只根据公开行动推断身份，不读取未公开真值。
5. **AI 决策解释与难度档**：展示候选评分和风险，难度改变搜索而不是偷看信息。
6. **完整行动重放**：导出 seed、检查点和规范化决策，逐事件复现牌局。
7. **单文件冷启动预算**：画像按本局武将惰性解码，约束内存与首次可交互时间。
8. **数据驱动规则契约**：统一卡牌、技能的费用、目标、时机与提示来源。
9. **属性与状态机测试**：随机生成非法决策和中间状态，持续验证牌唯一性与恢复等价。
10. **长局信息压缩**：把重复群体结算聚合为可展开摘要，减少视觉噪声但保留完整证据。
