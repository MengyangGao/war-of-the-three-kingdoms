# 三国杀 · 离线版（Legends of the Three Kingdoms — Offline）

一个**完整、可玩**的离线单机三国杀，纯前端实现，双击即玩，无需联网、无需安装。

## 如何开始

**直接双击打开 `index.html`** 即可（现代浏览器 Chrome / Edge / Safari 均可）。
无需服务器、无需网络。

- 选择玩家人数（3–8 人）与你的武将（默认随机）。
- 点击「开始游戏」。你的身份、座次随机分配。

## 玩法

身份局：
- **主公 + 忠臣** 为一方，需消灭所有反贼与内奸；
- **反贼** 需杀死主公；
- **内奸** 需成为最后的幸存者。

操作：
- 轮到你时，点击**手牌**或下方的**技能按钮**使用；需要目标时点击对应**角色**，再点「确定」。
- 其他角色对你使用【杀】等时，会弹出提示，点击【闪】等手牌响应，或点「放弃」。
- 右上角「战报」可展开完整日志。
- 对局结束会公布所有身份，可「再来一局」。

## 内容

- **武将 27 名**，覆盖魏 / 蜀 / 吴 / 群四国，含性别、体力、称号与技能（奸雄、反馈、鬼才、刚烈、洛神、倾国、武圣、咆哮、龙胆、马术、铁骑、观星、空城、制衡、苦肉、英姿、反间、国色、流离、谦逊、连营、结姻、枭姬、急救、青囊、无双、离间、闭月、护驾、激将……）。
- **卡牌**：基本牌（杀 / 火杀 / 雷杀 / 闪 / 桃 / 酒）、装备牌（诸葛连弩、雌雄双股剑、青釭剑、寒冰剑、青龙偃月刀、丈八蛇矛、贯石斧、方天画戟、麒麟弓、八卦阵、仁王盾、藤甲、赤兔 / 大宛 / 紫骍 / 的卢 / 绝影 / 爪黄飞电）、锦囊牌（无中生有、过河拆桥、顺手牵羊、决斗、借刀杀人、火攻、铁索连环、无懈可击、五谷丰登、桃园结义、南蛮入侵、万箭齐发、乐不思蜀、兵粮寸断、闪电）。
- 完整的距离与攻击范围、判定、濒死求桃、无懈可击连锁、连环传导等机制。

## 美术与演出

- **武将立绘**：24 名武将采用**公有领域历史画像**（清代《历代帝王圣贤名臣像》等，来自维基共享资源 Wikimedia Commons），作为角色面板与图鉴背景；其余 3 名（黄月英/陆逊/华雄，无合适公版画像）使用按国别自动生成的印玺式徽章立绘。
- **卡面美术**：每种卡牌都有独立的内联 SVG 图标（刀/剑/矛/斧/戟/弓/弩、盾/八卦/藤甲、坐骑、桃/酒/闪、火焰/雷电/箭雨/锁链/卷轴等），按类型着色。
- **动画/过程**：出牌时卡牌从出牌者飞向中央、目标高亮光环、伤害抖动与飘字、判定翻牌、回合/阵亡横幅、体力勾玉变化；**攻击/锦囊连线**从来源射向目标、**命中火花**、**濒死暗角**（vignette）、连环/闪电的链式特效、装备上马/穿甲的即时动画，事件随后归档进战报。
- **离线音效与音乐**：内置 `js/72-sound.js`，用 **WebAudio 实时合成**打击/出闪/摸牌/回血/判定/阵亡等音效与循环背景乐，无任何外部音频文件，纯离线。首次点击「开始」时激活音频（浏览器手势策略）。
- **可点击详情**：
  - 顶栏「📖 图鉴」——按势力浏览全部武将（立绘+全技能说明）与全部卡牌（规则说明）。
  - 点击任意角色面板 / 头像 → 该武将资料卡（立绘、国别、性别、体力、技能全文、当前装备）。
  - 点击自己的技能标签 → 技能详情；点击装备/判定区/中央出牌 → 卡牌详情；不可操作时点手牌亦可查看；右键（触屏长按）任意卡牌同样可看。
- **交互式技能选择**：观星（诸葛亮）弹出强制排序弹窗，逐张切换「留顶／置底」；观星、观自等「亮牌／改判」由你亲自决定；【杀/闪/无中生有…】的「视为」转化牌也由你选择目标与用途。
- **战报常驻可用**：点击「📜 战报」侧栏展开时，牌桌自动收窄让位，**可一边看战报一边操作**，互不遮挡。
- **最新战况条**：牌桌中央实时显示最近一次关键事件（出牌/伤害/回复/技能/判定/阵亡…），事件同时归档进战报。
- **牌面参数可见**：坐骑显示 +1/-1（绿/蓝角标），武器显示「范围N」，防具标「防具」，延时锦囊有独立配色。
- **本方身份自见**：你始终能看到自己的身份（主公/忠臣/反贼/内奸），仅对其他玩家隐藏。
- **AI 身份推理**：AI 之间知晓真实阵营，但对**人类玩家**采用**怀疑度/身份推断**模型——根据你攻击/相助的对象动态更新对你的敌友判断，而非上帝视角，兼顾对局的决断性与真实感。
- **移动端 / 触屏**：响应式布局自适应窄屏，卡牌**长按**查看详情；节奏、音效、音乐、音量等设置用 localStorage 持久化；「设置」内可**重新开始**回到选将。
- 顶栏「⚙ 设置」——调节游戏节奏、开关音效/背景音乐、调音量、查看操作提示、重新开始。

## 资源与版权

- 武将历史画像取自 **Wikimedia Commons 公有领域（Public Domain）** 素材，仅用于本地离线游戏展示。
- 卡牌图标与徽章立绘均为本项目**程序化生成的 SVG**，无第三方版权。
- 重新抓取立绘：`python tools/fetch_generals.py`（需 `pillow`，见 `requirements.txt`）。该脚本会从维基共享资源联网抓取**24 名已有合适公版画像**的武将；黄月英/陆逊/华雄无合适公版画像，继续使用程序生成的徽章立绘。

## 测试

Node 规则测试无需安装依赖：

```bash
npm run check               # 脚本顺序、数据引用、牌堆和资源结构校验
npm test                    # 75 项规则断言 + 濒死测试 + 60 局 AI 对战
npm run test:stress         # 500 局 8 人压力模拟
node test/run.js 120 8      # 跑 120 局 8 人 AI 对战，校验无异常、牌数守恒、胜负合法
node test/dump.js 1 8       # 打印某个种子的完整对局日志
```

界面测试需安装 `requirements.txt` 与 Chromium：

```bash
pip install -r requirements.txt
playwright install chromium
npm run test:ui
```

完整测试说明见 [`docs/TESTING.md`](docs/TESTING.md)。本轮审计的验证结果与未能复验的范围见 [`docs/AUDIT.md`](docs/AUDIT.md)。

## 规则口径与取舍

- 以游戏内卡牌和技能描述为可执行规则口径；部分武将能力是适合单机的简化版本，不宣称完整复刻某一官方年份或扩展包。
- 仅支持局内重开与设置持久化；不支持对局中途存档/读档。
- 保留经典脚本顺序加载，以满足直接双击离线运行；模块依赖和扩展约定见架构文档。
