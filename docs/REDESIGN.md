# “三分天下 · 风云牌局”重构规格

## 体验目标

玩家进入页面后十秒内理解题材、模式和开始方式；进入牌局后不依赖规则记忆即可判断当前阶段、可用卡牌、合法目标和下一步；任何状态变化都能从桌面反馈与战报中追溯。

## 信息架构

### 开局大厅

- 品牌区：原创名称、短说明、离线与开放资产标记。
- 快速设置：人数、难度/节奏、随机或指定武将。
- 武将画廊：按势力筛选，卡片展示体力、定位和技能摘要；键盘可选。
- 固定主按钮：选择完成后始终可见，清楚展示将开始几人局。

### 对局桌面

- 顶部命令栏：回合归属、牌堆状态、图鉴、战报、设置。
- 阶段轨道：准备、判定、摸牌、出牌、弃牌、结束六段，当前段突出并提供文本。
- 对手座次：优先展示姓名、体力、手牌数、装备/判定状态；身份信息遵循规则。
- 中央结算区：最近出牌、来源与目标连线、伤害/回复反馈。
- 玩家控制坞：自己的状态、技能、扇形手牌与统一指令栏。
- 战报抽屉：默认关键事件，支持筛选；打开时不遮住主要操作。

## 统一交互状态机

```text
浏览 → 选择卡牌/技能 → 选择合法目标 → 确认 → 结算 → 浏览
                         ↘ 取消 ─────────────↗
响应请求 → 选择响应牌或放弃 → 结算
```

- 浏览：悬停或聚焦提供大图预览，不改变规则状态。
- 已选：卡牌抬起并显示“已选择”文字；合法目标显示轮廓和动作标签。
- 不合法：保持可查看，但降低对比度并解释原因；不静默失败。
- 确认：固定指令栏显示卡名、目标、确认与取消；单目标的高频响应可明确设置为快捷出牌。
- 结算：暂时锁定重复提交，动画结束前规则状态已经确定。

## 视觉系统

- 色彩：墨黑 `#151815`、宣纸 `#efe4c5`、漆红 `#a73a2a`、铜金 `#c79a4a`、竹青 `#395f4b`。语义色独立于势力色。
- 字体：仅使用系统中文字体栈，避免字体文件授权与加载问题；标题使用字重和字距建立书卷感。
- 层级：背景纹理由 CSS 渐变生成，面板采用低透明漆面；卡牌使用纸面高对比，不使用侵权边框或布局。
- 动效：100–180ms 用于悬停和选择，240–420ms 用于出牌与结算；支持 `prefers-reduced-motion`，减少位移和闪烁。
- 可访问性：正文对比度、明显焦点环、44px 主目标、ARIA 标签、实时提示采用 `aria-live`；颜色之外始终提供文字/形状线索。

## 代码边界

| 层 | 责任 | 禁止事项 |
| --- | --- | --- |
| Engine | 规则、牌堆、回合、结算 | 访问 DOM、播放动画 |
| Presentation | 从游戏状态生成只读视图模型 | 修改规则状态 |
| Components | 生成桌面、卡牌、玩家、指令栏 DOM | 直接调用复杂规则 |
| Interaction | 将点击、键盘、触摸映射为人类代理动作 | 自行判断最终合法性 |
| Effects | 动画、声音、战报展示 | 决定伤害或胜负 |

经典脚本加载与 `file://` 离线能力暂时保留。UI 拆分为小型全局模块并使用单一命名空间，待功能与测试稳定后再评估 ESM 打包；避免在一次迁移中同时改变规则与装载方式。

## 迁移顺序与验收

1. 品牌、文案、资产账本与设计令牌。
2. 开局大厅和武将选择组件。
3. 牌局壳层、阶段轨道、对手面板和玩家控制坞。
4. 统一选择/确认状态与键盘交互。
5. 动画、声音、响应式和减少动效模式。
6. UI 自动化、压力模拟、资产审计和浏览器视觉验收。

每个阶段独立 Git 提交；`npm test` 必须始终通过，UI 阶段还需覆盖 3、5、8 人局与 390px、768px、1440px 三档视口。
