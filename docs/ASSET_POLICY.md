# 开放资产政策

## 准入条件

仓库中的第三方视觉、音频与数据资产必须满足以下之一：Public Domain、CC0、CC BY、CC BY-SA，或经过逐项复核的 OSI/FSF 兼容许可。每个资产必须记录本地路径、作者、原始文件页、许可名称与许可链接。

默认不接收 NC（非商业）、ND（禁止演绎）、“仅供学习”、来源不明、搜索引擎预览图、商业游戏截图或无法定位到原始授权页的内容。是否免费获取不等于允许再分发。

## 引入流程

1. 优先使用 CSS、Canvas 或项目自绘 SVG；其次使用公有领域/CC0；需要署名资产时再考虑 CC BY/CC BY-SA。
2. 只从原始作者页、Wikimedia Commons 文件页或可信开放资产仓库下载。
3. 保存原始 URL 和文件页，不只保存 CDN 地址。
4. 运行 `npm run audit:assets:write`，检查许可、尺寸与 SHA-256。
5. 在 `assets/ATTRIBUTION.md` 和游戏内“来源与许可”页展示署名。
6. 使用 Git 独立提交资产及账本变更，便于审查和撤回。

## 修改与分发

- 修改 CC BY/CC BY-SA 内容时记录裁剪、调色、压缩等变化。
- CC BY-SA 改编资产按同版本或兼容许可分发；项目代码与其他独立资产不因此自动改变许可。
- Public Domain/CC0 也保留来源，且继续检查商标、隐私、人格权、文化遗产和地域性限制。
- 未经明确授权，不使用其他游戏的名称、徽标、角色造型、界面截图、卡面排版或独特文案。
