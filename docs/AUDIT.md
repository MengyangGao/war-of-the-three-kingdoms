# 独立审计记录

## 第二轮深度审计（2026-07-26）

本轮重新从完整源码、固定种子整局模拟和单文件构建链路独立检查，不把上一轮“测试通过”当作系统已经没有缺陷。基线虽有 83 项断言和 500 局守恒结果，但仍发现四个事实性缺口：

- 只校验 8 人局会掩盖人数差异；基线 300 局矩阵中，6 人反贼 194 胜、8 人反贼 193 胜，内奸分别只有 19/11 胜。
- 原 `snapshot()` 只有牌 ID，没有牌面表、恢复器和安全恢复边界，实际不能读档。
- 98 条日志调用仅少数包含行为双方；角色事件条仍需从中文名字反查参与者。
- `js/70-ui.js` 仍有 1051 行和大量独立 `setTimeout`，与“统一时间线、拆分巨型模块”的目标不一致。

### 十项本质性优化

| # | 方向 | 实质性目标与验收标准 | 状态 |
|---|---|---|---|
| 1 | 逐人数身份平衡矩阵 | 3–8 人分别跑固定种子；0 异常、0 牌/事件问题、P95 ≤ 100 回合、任一主阵营不超过 70%、内奸达到分人数最低线 | 已实施 |
| 2 | 真正可恢复的执行状态 | 序列化完整牌面表、RNG、UID、玩家、日志和下一行动者；只允许 `readyTurn` 安全点恢复；恢复后最终胜方、回合数和所有牌区与原局一致 | 已实施 |
| 3 | 结构化事件模型 | 所有日志统一为 schema 2，具备事件 ID、类型、回合、阶段、参与者；技能记录技能键；UI 不再解析中文名字 | 已实施 |
| 4 | UI 按职责拆分 | 把提示/选择、短暂视觉效果、活动、弹窗从核心交互中分离；主 UI 从 1051 行降至 777 行，并以独立脚本做语法/加载校验 | 已实施 |
| 5 | 单一可取消时间线 | 视觉节点、长按、AI 节奏和引擎停顿都进入命名 scope；可单任务、按 scope、全局取消且 Promise 必须释放 | 已实施 |
| 6 | 隐藏身份信念模型 | AI 不得直接读取其他玩家真实身份；每个观察者维护独立概率与证据衰减，公开行为才更新判断；以公平 AI 重跑平衡矩阵 | 待实施 |
| 7 | 决策解释与难度档 | 每个 AI 动作返回候选评分、主要理由和风险；休闲/标准/进阶只改变搜索与信息噪声，不修改规则或偷看身份 | 待实施 |
| 8 | 可重放行动日志 | 记录 seed、检查点和规范化决策；支持导出/导入一局并逐事件重放，异常报告可精确停在事件 ID | 待实施 |
| 9 | 单文件冷启动优化 | 画像从首屏同步 Base64 解码改为按本局武将惰性 Blob；用性能标记约束可交互时间和峰值 DOM/内存 | 待实施 |
| 10 | 数据驱动规则与属性测试 | 把卡牌/技能费用、目标、时机声明为可校验契约；随机生成非法决策和中间状态，在每个移动/结算边界验证牌唯一性与合法区 | 待实施 |

### 本轮已取得的证据

- 单元与规则断言：93 项通过。
- 200 局 × 6 种人数平衡矩阵通过；8 人结果为主忠 76、反贼 110、内奸 14，P95 61 回合。
- 额外 500 局 8 人压力结果：主忠 197、反贼 277、内奸 26；相比上一版 158/322/20，阵营差距收窄且内奸胜局增加 30%。
- 检查点恢复回归证明：同一安全点的原局与恢复局最终胜方、回合数、牌堆、弃牌堆、手牌、装备和判定区完全一致。
- 整局模拟同时验证事件 schema；不是只检查最终牌数。

浏览器的最终人工观感仍应在允许的真实浏览器环境复验。本轮不把 Node 语法、规则模拟或旧版浏览器截图冒充为新版 UI 的真实点击证明。

## 范围

## 本轮修复

### 严重：状态与规则正确性

- 统一卡牌移动事件；获得、使用、装备、替换和判定区移动现在都会准确触发失牌区域事件。
- 修复虚拟延时锦囊容器与实体子牌同时残留导致的牌重复。
- 防止正在结算的锦囊被弃牌堆立即重洗并在自身效果中摸回。
- 增加 Agent 决策规范化和出牌动作二次校验，拒绝越权卡牌、重复/非法目标和伪造费用。
- 将判定拆分为改判与最终结果两个时序，使【天妒】取得改判后的最终牌。
- 【闪电】移交时跳过已有闪电的角色。
- 【寒冰剑】不再以“弃 0 张牌”替代伤害。
- 【贯石斧】可正确选择手牌和装备区的两张牌作为费用。
- 【雌雄双股剑】改由目标选择弃牌或令来源摸牌。
- 伤害被取消时不再错误触发【麒麟弓】。
- 【铁索连环】允许以自己为目标；修复重铸标记在选项层丢失、UI 两种用法互相覆盖的问题。
- 【结姻】在使用者满体力、男性目标受伤时仍可发动。
- 武圣、奇袭、国色、急救等“牌”转换支持手牌或装备区；倾国仍按描述仅使用手牌。
- 洛神改用统一判定流程，支持改判并允许停止继续判定。

### 高：UI 与异步稳定性

- 对手面板缓存签名加入可选/已选目标、当前回合、连环、翻面和身份公开状态，避免目标不可点或显示不刷新。
- 装备区卡牌可在制衡、流离、贯石斧和转换技中被实际选择，并有明确选中样式。
- 修复交互状态机达到最大选牌数后仍继续追加的问题。
- 动画队列支持多个等待者；动画异常不再永久卡住队列；清空队列会释放未执行任务。
- 修复救援动画字段名不一致。
- 启动参数会校验节奏范围，重复点击开始按钮不会创建两局并发游戏，异步启动错误不再成为未处理拒绝。

### 中：可维护性与诊断

- Game 构造、setup、发牌、start 和武将分配增加前置条件与重复调用保护。
- 恢复体力事件记录实际恢复量，而非请求量。
- 修复 AI 判断攻击来源敌友时参数方向反转。
- 新增结构校验、分层 npm 脚本、架构文档、测试说明和忽略规则。

- `npm run check`：通过；14 个脚本、27 名武将、130 张牌、24 张立绘映射有效。
