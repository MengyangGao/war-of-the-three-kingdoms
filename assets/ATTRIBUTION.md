## 使用规则

- 公有领域图像仍保留来源链接，便于复核出处、人格权或其他地域性限制。
- CC BY / CC BY-SA 图像必须保留作者、文件页、许可链接，并标明修改；CC BY-SA 的改编版本继续使用相同许可。
- 项目名称、标志、商标与角色商品化权不因图像采用开放许可而自动获得授权。
- 卡牌图标、印玺占位图与界面纹理由本项目通过 SVG / CSS 程序化绘制，不引用第三方游戏画面。
